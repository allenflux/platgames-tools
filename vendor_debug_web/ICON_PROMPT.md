# 工具图标

由内置 `image_gen` 工具生成，保存为本目录 `icon.png`，用于页面标识和 favicon。

提示词：

Use case: logo-brand. Asset type: a single square favicon and small app header icon for an internal Chinese vendor game debugging web tool. Primary request: make an original clean app icon, a bold near-black outlined game controller integrated with one simple circular refresh arrow (token renewal), on a flat warm yellow rounded-square tile. This tool uses a restrained white/gray admin interface with charcoal buttons and a small yellow brand mark, so match that utilitarian look. Flat vector-like raster rendering, strong geometric silhouette, minimal detail, centered, balanced, clear at 24 and 32 pixels. No letters, no words, no numbers, no gradients, no shadows, no photographic textures, no 3D, no extra motifs. The yellow tile fills the image with subtly rounded corners and transparent space outside the corners. One icon only, square 1024 by 1024 PNG with genuine transparency outside the tile.
